# AI Usage Disclosure

AI tools were used during the development, testing, documentation, and preparation of this project as an aid for:

- Explaining computer networking concepts, including UDP, reliable data transfer, Stop-and-Wait, Go-Back-N, Selective Repeat, sliding windows, acknowledgements, retransmissions, and adaptive Retransmission Timeout (RTO).

- Reviewing code structure and discussing implementation approaches.

- Assisting with debugging guidance, Java compilation, PowerShell terminal commands, Git operations, and GitHub integration.

- Explaining packet formatting, checksums, CRC32, SHA-256 file integrity verification, UDP transport, and retransmission handling.

- Understanding and interpreting experiment results, including RTO sensitivity, packet loss, packet reordering, window-size variation, and the use of random seeds in channel-emulator testing.

- Helping plan and execute basic file-transfer tests for Stop-and-Wait, Go-Back-N, and Selective Repeat.

- Preparing test commands for the channel emulator and explaining network impairment configurations such as packet loss, duplication, corruption, delay, jitter, and reordering.

- Assisting with the organization and documentation of terminal outputs and experiment logs. Some log files were prepared as transcriptions of terminal screenshots and are labelled accordingly; they are not original automatically captured terminal logs.

- Assisting with preparation of experiment explanations, presentation notes, and potential viva questions.

- Providing guidance on organizing project files, maintaining documentation, and committing and pushing changes to GitHub.

AI assistance was used as a development and learning aid. All team members are responsible for reviewing, understanding, testing, and being able to explain the code, implementation decisions, experimental procedures, and results included in the final submission.

The final disclosure should accurately reflect all AI assistance used during the project. AI-generated explanations and suggestions were reviewed by the team, and project results should be supported by the actual implementation and recorded test evidence.
